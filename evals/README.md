# 方法评价与当前证据

v0.1 验证了结果结构、交互闭环与一次留出论文的独立试用。当前证据不足以宣称 Skill 在研究判断质量上优于强 Prompt，也不足以测量作者真实历程还原准确率。

## 案例与试用协议

ResNet 与 CRISPR 是执行者制作、来源自查的打磨案例。随后固定 Skill 与 Schema，使用未参与打磨的 LIGO 论文做两次独立试用：一份使用发布包 Skill，另一份只收到 [强基线任务](baseline-prompt.md)。两位执行者由同一 Codex 主会话派生，继承相同模型配置，没有显式模型覆盖；各自没有可获取的逐调用模型标识或 token 统计，原记录保留 null。

两份任务均获得 arXiv 1602.03837v1 的同一 PDF 与同一逐页文本，禁止外部检索，约定正文 3500–5000 中文字符；均禁止读取打磨案例或另一试用产物。Skill 另需生成结构化结果和执行校验。此处比较的是完整 Skill 工作流与直接 Prompt，输出负担并不相同，不能把耗时视为模型推理效率对照。

原论文 PDF SHA-256：`e5e864c23d015b69be17e5b5d51b5b462d2829353a867513414b6728f54589c4`。逐页文本 SHA-256：`d0c5a8bf57b7340bb6e7926a1b2d0cab978cbf1a1917283b6ba7b2767a70c9f0`。PDF 与文本是同一来源的两种表示。

文本提取方式为 pypdf，逐页添加 `=== PDF PAGE N (index N-1) ===` 标记；不把 PDF 附件上传到仓库。冻结哈希用于识别本次所用文件；v0.1 首发仍在同一开发会话中修正了输出粒度及校验器，哈希不代表首发源码已逐字复现该试用包。

留出仅指没有用此论文修改前一版方法；基础模型可能已接触这篇著名论文，不能视为完全未知历史。两份原始报告、运行记录与冻结文件哈希保存在 [ligo](ligo/) 中。原始论文不随仓库分发。

## 具体比较与发现

以下为项目执行者在知道生成方式后做的模型审阅，未盲评、无人类评分，不作为独立真值。

- **两者均有实质分析。** 都把双站同时出现与共同环境误差分开，都说明误警率不是本事件为假的概率，也都区分共享数据的两种算法与独立观测。强基线没有被故意弱化。
- **两者均保留历史边界。** 都只把“通用低延迟搜索先触发、随后匹配滤波恢复”作为来源明说的局部先后，没有把它扩展成整个项目起源。
- **Skill 的可验证收益主要在结构。** 每条路径保存独立已知条件；讨论包可只携带当前路径，证据 ID、版本和节点不依赖重新理解自由文本。这直接支持阅读器和修订流程，尚不能证明科研启发更强。
- **额外代价可见。** Skill 用时更长、调用更多工具，Markdown 自动展开主张会增加重复阅读；本次未取得模型 token 或费用，不能换算成本。
- **发现一项输出粒度问题。** 原始 Skill 结果将一章的多节点论述放在一个 block 中，虽结构有效，但段落到证据的联动太粗。公开阅读案例拆成短段落并按节点映射，Skill 的 output.md 也补充了明确要求。冻结试用结果保持原样，因此该修正未获得第二次独立留出验证。

## 公开案例的编辑说明

examples/ligo-2016.json 从原始 Skill 输出派生：添加原论文公开链接、修改示例身份、说明文本与 PDF 是同一来源，并细分正文段落到节点和主张的映射。没有把未复验结果改为独立核查，也没有将推断升级为事实。原始试用输出另存，避免把编辑后的界面案例冒充未经干预的评测结果。

## 节点续聊与修订闭环

从原始结果的 P2/N2 导出讨论包，执行者先依据局部包回答“6%的环境扰动上限能否排除所有共同误差”，再按测试请求中明确采纳的修改生成 v2。修订补充传感器覆盖不足或耦合不稳定时的未决分支，新增行动建议保持 hypothetical，未修改论文来源和原始证据。

原版、讨论包、回答、修订摘要、新版与记录均保留。validate 与 revision 检查通过；六个旧节点保留映射。浏览器测试用这些实际产物重放导入、节点导出、新版导入与旧版保留。它是软件与会话衔接的闭环验证，不是人类学习效果评价。

## 后续评价方法

按关键主张核对证据忠实度，按核心节点比较决策质量，按判断方法检查适用条件。随机化报告顺序、隐藏生成方式，记录具体问题片段与检查数量；有作者历史回顾时，将用于生成和用于独立参照的材料分开。若要验证学习迁移，另给相近但不同的问题，请读者提出下一步行动及依据。
