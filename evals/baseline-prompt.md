# 强基线任务

仅使用给定论文 PDF 和同一 PDF 的逐页提取文本，不外部检索。用中文从该论文反推可能的研究形成路径，帮助读者学习科研判断。

直接一次提供完整报告，六部分为：核心问题与最终工作、可能起点、关键决策、失败与替代方向、贡献与证据收束、可迁移判断。

明确区别原文明示、有依据推断和学习用假设；关键事实标真实来源章节、图表和页码。不将论文叙述顺序或结果写成作者实际研发史。保留竞争路径与各自前提，不把最终结果当作早期已知。关键节点给具体选项、可区分解释的检验、不同结果后的行动变化；迁移经验给适用情境与边界。

正文约 3500–5000 中文字符，实质优先，不凑节点数或故事。记录实际起止 UTC、观察到的工具调用次数、实际材料和可获取用量，未知值为 null。不需要结果 JSON、Schema 或阅读器格式。

完整试用分派还限制其不能读取 Skill、案例、校验器或其他评测目录，输出到隔离的工作目录；未附带预期答案。
