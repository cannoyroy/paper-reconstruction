## 具体发现：非盲模型审阅

执行者知道生成方式，并回查部分关键事实；这些观察不是独立真值或人工反馈。

- **双方保留条件。** Skill的s2-b3与基线比较段都发现ResNet表6转引的Highway 19层错误率7.54不同于本次Highway v1表1的92.24%准确率，没有混成统一对照。已回查两份原文表格。
- **双方都有实质判断。** 都区分门控混合与无门残差、优化与泛化，保留块后ReLU、Highway的40次搜索与不同宽度、900层实验仅80轮等条件；这些事实已回查。没有将发表顺序写成继承史。
- **各有细节，不能判胜负。** Skill的s6-b3强调合理初始化搜索空间和调参机会；基线B17区分从头重训替换组件与训练后临时干预，防止将依赖性误读为不可替代性。两者均给出不同结果后的行动。
- **结构约束发挥作用。** 基线首次把跨论文主张放进单篇比较单元格，被校验拒绝；拆成逐篇来源陈述后通过。结构检查不能验证科学支持关系。
- **导出缺陷已修复。** 冻结CLI没有在Markdown完整展开节点选项、判别结果和行动，信息仍在JSON。首发已补齐，原始试用Markdown保留缺陷，新导出由软件验证，不冒充重新生成的独立试用。
- **语义仍需检查。** 有些主张合并论文陈述与读者的范围解释。标签、引用有效也不代表每句都为原文明示。可读性、科研启发和实际学习收益尚无人类评价。

## 推荐、拒绝与续聊

实际查询围绕缺少的传播／门控判别证据，只推荐Identity Mappings v1一篇，并停在pending。测试编排随后提供明确标记为simulated_test的接受和拒绝指令，分别完成三篇及原始两篇分析。拒绝后未再次推荐，候选只留检索记录。[详细时序](consent/protocol.md)保留真实工具行为和模拟选择的区别。

接受分支实际导入网页，打开REL_HI推断和来源并下载[讨论包](consent/accepted/browser-discussion.json)。Codex只读局部包直接回答，提出[提案](consent/accepted/revision-proposal.md)，等待明确模拟采纳后读取完整分析并生成[v2](consent/accepted/analysis-v2.json)。v2收窄门控比较范围，区分conditional_support与compatible；论文、版本、证据、采纳清单和旧版哈希不变。浏览器测试重放新版导入、旧版保留及拒绝分支；不是人类真实批准。

## 覆盖与局限

- 单元测试：0／1／3候选、第四篇拒绝、全部／部分／拒绝／未答复、别名重复、检索失败、不可读部分结果、归属、对称关系、路径隔离、讨论范围、版本冲突。
- 短模型行为探针：歧义标题、同名作者、组别未知、重复版本、不可读材料、仅提供材料与模拟三候选决定，见[行为记录](behavior/)。这是受控输入，不是实际检索三篇的召回率评价。
- Playwright：新旧导入、卡片、表格、两类地图、筛选保留正文、讨论复制与回退、持久化、移动布局及真实修订产物；桌面和手机截图由执行者查看。
- 真实检索只测一组和一条候选，不能评价学科覆盖或推荐质量分布。大批量输入、长期恢复、多语言标题及各类PDF尚未逐项实测。
- 来源定位不等于支持正确。首次多篇试用以模型自审为主，不代表复现实验、同行审稿、作者确认或历史还原准确率。

冻结后修复了导出展开、阅读状态、地图布局、检索前状态和失败查询记录；方法与纳入规则未改变。当前校验器再次检查保留产物：`pnpm evals:check`。冻结快照哈希不等于发布包哈希。

### 生物学试用的协议偏差

执行者在provided_only任务中为了定位已给论文做了一次精确标题搜索。未将旁出的论文纳入证据，实际分析仍为两篇，但搜索本身没有完全遵守本轮不检索约束。不能把它记为“仅提供材料行为通过”。原始记录保留偏差；首发规则进一步明确：只能直接读取给定文件和链接，失败时留缺口或请求材料，不能以同篇定位为由使用搜索引擎。针对这一路径另做短回归；不把回归当成重新运行了整套生物学分析。
