# 多篇方法样稿：ResNet 与 Identity Mappings

状态：实施者基于固定版本原文制作的打磨样稿；不是独立评测，也不是作者历史记录。

输入为 arXiv:1512.03385v1 与 arXiv:1603.05027v1。线索为相同作者；不据此推断导师关系。当前样稿仅使用这两篇材料，补充检索另作交互验证。

第一篇把“表达得出来”与“优化器找得到”分开：Figure 4 的训练误差和验证误差同时提供依据，残差与 plain 对照保持结构和计算量尽量一致。第二篇进一步把跳连 h 和相加后的激活 f 分开分析。两篇可以组成从表示重写到传播路径条件的逻辑主线；论文中的讲解和消融顺序不足以恢复实际研发顺序。

关键比较不能只说“恒等更好”：原论文 Table 3 的 34 层投影方案 C 有良好结果；后续论文在 110 层、所有捷径使用投影时出现更高训练误差。后者改变了深度、数据及实验设置，不是对前者普遍结论的直接证伪。更有价值的下一步是在匹配设置下逐项改变捷径操作和激活位置，观察训练曲线；训练损失低而验证变差时转向泛化解释。

预激活同时影响传播和 BN 所在位置，论文 §4.2 本身讨论优化与正则化两方面。联合推断不能将所有改进归因于唯一机制。ImageNet 比较还需注意后续论文 §4.4 使用 320×320 测试裁剪，不能直接拿跨篇排行榜数字当受控实验。

据此冻结样稿结构：逐篇证据卡 → 可比条件与比较表 → 主张及关系 → 具备反向结果的决策节点 → 六部分联合正文。允许事后比较路径使用两篇结果；候选起点路径只保留第一篇作为已知信息。每条主张保存实际核查位置、支持范围及竞争解释。

此稿检验的具体价值是：将“多篇都说捷径有益”转化为“在什么设置下，应先检查传播路径，什么时候又应改查泛化或预算”。
