# 生物学留出验证：阶段与限制

本目录属于方法冻结后的独立模型试用。未读取项目已有案例、evals、其他试用输出；未修改主源码或冻结发布包。

## 实际材料

- Jinek 等，2012：实际读取 PMC 作者稿 HTML 的主文 P1–P13、主图图注，以及身份/合作信息。单独下载并目视 Figure 4。PDF URL 实际返回浏览器验证 HTML，已改名保存为 jinek-pdf-access-response.html，**没有把它当作成功取得的 PDF**。未读取补充材料，特别是周转结论所指的 S6B。
- Sternberg 等，2014：下载 eScholarship 提供的合法公开作者稿，17 页（库封面加作者稿 16 页）。已读主文、Methods、主图图注和身份信息；目视 Figure 3、4。没有读取 Extended Data、补充视频或原始轨迹。PDF 文件页索引比作者稿印刷页号相等是因为前置封面：例如作者稿第 15 页为 PDF index 15，文件第 16 页。
- 取材均属于指定两篇论文。HTML/PDF、提取文本、实际查看图片的 SHA256 见 material-hashes.json。引用支持范围区分了正文转述、图像核对和未读补充。

## 协议偏差：必须保留

请求材料策略是 provided_only，本应跳过外部搜索。PMC 首次工具访问返回验证页后，执行过**一次精确标题外部搜索**以定位指定 Jinek 全文。这仍属于本次协议偏差，不能写成“没有检索”或“完全遵守仅提供材料”。

检索式为 `"A Programmable Dual-RNA-Guided DNA Endonuclease in Adaptive Bacterial Immunity" pdf Jinek 2012`，域名限定 berkeley.edu、science.org、pmc.ncbi.nlm.nih.gov。搜索返回过其他论文的片段，但没有打开、分析、引用、推荐或纳入这些论文。候选清单保持为空；联合结论只依赖指定两篇的实际读取材料。之后未为修复记录额外取材。

## 阶段结果

1. 固定两篇身份与实际作者稿版本；公开作者重合、机构与贡献只作为合作线索，不推断指导关系。
2. 冻结分析清单为这两篇。没有模拟候选采纳，不把检索偏差藏入采纳记录。
3. 建立两张证据卡、两条比较轴、三个决策节点、一个事后比较路径及两条关系。
4. 机制判别保留具体竞争解释：PAM的结合前/后作用、随机成核/方向性解链，以及周转分歧的条件或计量解释。每个节点包含不同观察下的后续行动。
5. JSON 完成后使用冻结包 CLI 校验和导出。report.md 是 CLI 原始输出，未手工改写。

## 结论边界

可读主文足以完成六部分有限联合报告，故 analysis.status=complete；每篇 read_status=partial 表示补充与部分图像没有读到。结构校验不能消除取材协议偏差，也不能把模型自审升级为人工质量评审。

2012正文的多轮解释与2014体外单轮特征被保留为未决关系；补充条件未核查，不能宣布哪篇“错误”。研究地图是文本支持的问题联系，不是研究者真实构思史。
