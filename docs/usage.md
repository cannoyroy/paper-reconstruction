# 使用指南

## 生成完整复盘

在已安装 Skill 的 Codex 项目中提供明确版本的论文链接、可读取 PDF 或正文。默认一次交付完整报告与结果包；仅论文身份、关键材料或运行条件无法确定时先询问。

指定“仅提供材料”关闭外部补读；默认只围绕关键未决问题补读公开资料。不能读取的图表、附录和链接会形成具体缺口。仅摘要输入可以产生部分结果，不会被标为已读全文。

从发布包安装时，Skill 目录中包括 rules、JSON Schemas 和自足的 Node.js CLI。保留整个目录；不要只复制 SKILL.md。宿主能力、支持状态见 host-support.md。

## 多篇联合分析

混合提供 PDF、链接、正文和标题，并说明把论文放在一起的理由。Skill 登记身份与版本，初读后做一次定向检索，最多推荐3篇。你可以全收、部分收或全拒绝；未回答时不会纳入候选。“仅提供材料”跳过检索。阶段文件保存为 collection_intake 和逐篇证据卡，中断后继续时核对清单和决定。

多篇页面提供联合正文、单篇证据卡、比较表、论文关系图和跨论文决策地图。筛选只定位或高亮，正文完整保留。地图之外的关系列表也可打开依据；手机比较表可以横向滚动。检索和采纳记录在材料清单中展开。

节点和关系详情都能复制或下载局部讨论包。增删论文或改用论文其他版本会建立新分析 ID，并登记派生关系；普通内容修订仍递增版本，同时记录节点和关系映射。

## 阅读与核查

打开阅读器并导入 analysis.json。导入先检查格式、ID、引用与路径关系；错误会保留原有可读报告。部分完成的分析有单独标记。

正文有序展示六部分内容。“主张与依据”列出当前段落的各项判断；分别检查它们的性质、证据类型、出处、支持关系、假设和竞争解释。来源定位与语义支持分别显示，不能把“仅相容”理解成“证实”。

选择路径会切换节点的假定已知信息。决策地图中的连线分别表示逻辑依赖、候选转折、替代、回退或有来源支持的时间顺序。地图不是默认的开发时间线。

来源定位可能是章节、图表、PDF 文件页或印刷页。PDF 文件页以阅读者看到的第几页显示；JSON 中 pdf_page_index 从零开始。定位粗时不会显示伪造的精确高亮。

## 继续讨论

选择节点，写下问题，点击“准备节点与提问上下文”。复制全文到 Codex，或下载讨论 JSON 与 Markdown。浏览器复制权限不可用时可手动选择文本。

讨论包包含当前路径的节点条件和必要主张、证据释义、来源位置；不含完整论文、全部节点或原会话历史。普通问题直接回答；勾选参与式判断后才引导你先判断。

如需修改报告，先查看修改摘要。明确采纳后让 Codex 读取原始 analysis.json，生成相邻新版本并执行 validate 和 revision 检查。重新导入后旧版仍在“本地记录”中。旧讨论继续对应旧版，不能悄悄改成新版。

## 保存、删除与移动设备

阅读器保存已打开的分析、所选路径、节点和阅读位置到此站点的 IndexedDB。导出 JSON 才能把结果带到其他浏览器。清理浏览器数据、无痕会话结束或存储回收都可能移除记录。

在“本地记录”中删除指定版本。删除只影响本浏览器，保留的导出文件不会被删除。存储失败时页面提示，当前仍可阅读、复制和导出。

移动设备通过“目录”打开导航，节点与证据在侧边抽屉显示；Escape 或关闭按钮返回正文。
