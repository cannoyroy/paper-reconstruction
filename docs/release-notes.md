# 论文研究复盘工作台 v0.2.0

从单篇研究决策复盘扩展到多篇论文联合分析，贯通 Codex Skill 与静态阅读器。

- 混合提供 PDF、链接、正文和标题，记录作者／课题组／相似性线索，先核实身份和版本。
- 初读后定向检索，一次最多推荐3篇，等待明确采纳；仅提供材料时跳过。拒绝和未答复不构成许可。
- 六部分联合报告、逐篇证据卡、条件比较、论文关系图及跨论文决策地图；允许多个研究簇和没有共同主线。
- CollectionAnalysisBundle 0.2.0、采纳阶段文件、关系讨论包、论文归属校验及节点／关系修订映射。
- 阅读器支持新旧格式、筛选定位、两类讨论、复制回退、移动抽屉与本地持久化；已有0.1.0记录保留。
- Skill 包含按需加载的多篇方法、新旧Schema、自足CLI；文件名跟随项目版本。

下载 Assets 的 paper-reconstruction-0.2.0.zip，将整个 paper-reconstruction 文件夹放入项目 .agents/skills/。升级安装时先备份旧目录，再用新包替换。辅助CLI需要Node.js22；网页不需要模型API，分析与讨论在Codex中完成。

本次使用固定材料做模型试用和强基线配对，另测采纳／拒绝与讨论修订闭环。模拟用户选择明确标记，不是人类质量评审。实际记录和限制见 [评价](https://github.com/cannoyroy/paper-reconstruction/tree/main/evals/collections)。不声称验证所有学科、作者真实历史或固定准确率。自动OCR、实验复现、账号、后端论文库和自动同步仍不包含。
